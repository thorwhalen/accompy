

# Architectural Analysis & Refactoring Instructions for `accompy`

## Current State Assessment

### What's Good ✓

1. **Pattern dataclasses** (`DrumPattern`, `BassPattern`, `CompingPattern`) — clean, immutable data structures
2. **`Score` as a domain model** — provides a unified representation of chord progressions
3. **`ensure_score()`** — good coercion/normalization pattern for flexible input
4. **Dual backend support** (MMA/builtin) — shows awareness of extensibility
5. **Dependency checking with UX guidance** — `print_setup_instructions()` is user-friendly

### What Needs Refactoring ✗

| Issue | Impact |
|-------|--------|
| **Monolithic `accompy.py`** (~1400 lines) | Hard to test, navigate, extend |
| **Tight coupling** — pattern selection, MIDI generation, audio rendering all interwoven | Can't swap components |
| **No protocols/interfaces** | No contracts for extensibility |
| **Pattern registry is a dict constant** | Can't register custom patterns at runtime |
| **Chord-to-notes is hard-coded** | Can't experiment with alternative voicings |
| **File-only output** | Blocks real-time use |
| **SoundFont path discovery is imperative** | Can't inject alternative synth backends |

```python
"""Protocols defining extensibility contracts."""

from typing import Protocol, Iterator, runtime_checkable
from .base import Score, AccompanimentConfig


@runtime_checkable
class ChordResolver(Protocol):
    """Convert chord symbols to MIDI notes."""

    def __call__(self, symbol: str) -> list[int]: ...


@runtime_checkable
class PatternSource(Protocol):
    """Provides patterns for a given style."""

    def available_styles(self) -> list[str]: ...


@runtime_checkable
class MidiEventGenerator(Protocol):

        chord_resolver: ChordResolver,

    """Renders MIDI events to audio."""

    def render(
        self,
        events: Iterator[MidiEvent],

    def render_to_file(
        self,
        events: Iterator[MidiEvent],
        config: AccompanimentConfig,
        output_path: Path,
    ) -> Path: ...
```

### Phase 3: Pattern Registry (Mapping Interface)

**Goal**: Replace the static `DRUM_PATTERNS` dict with a `MutableMapping` that supports runtime registration.

Create `accompy/patterns/__init__.py`:

```python
"""Pattern registry with runtime registration."""

from collections.abc import MutableMapping
from typing import Iterator


class PatternRegistry(MutableMapping[str, dict]):
    """
    Registry of accompaniment patterns by style.

    Implements MutableMapping for intuitive access:
        registry['bossa']  # Get patterns
        registry['my_style'] = {...}  # Register custom
        del registry['my_style']  # Remove

    Example:
        >>> registry = PatternRegistry()
        >>> registry.register_builtin_patterns()
        >>> 'swing' in registry
        True
        >>> registry['swing']['drums'][0].name
        'swing_basic'
    """

    def __init__(self):
        self._patterns: dict[str, dict] = {}

    def __getitem__(self, style: str) -> dict:
        if style not in self._patterns:
            raise KeyError(f"Unknown style: {style}. Available: {list(self._patterns)}")
        return self._patterns[style]

    def __setitem__(self, style: str, patterns: dict) -> None:
        # Validate structure
        required_keys = {"drums", "bass", "comp"}
        if not required_keys.issubset(patterns.keys()):
            raise ValueError(f"Pattern dict must have keys: {required_keys}")
        self._patterns[style] = patterns

    def __delitem__(self, style: str) -> None:
        del self._patterns[style]

    def __iter__(self) -> Iterator[str]:
        return iter(self._patterns)

    def __len__(self) -> int:
        return len(self._patterns)

    def register_builtin_patterns(self) -> None:
        """Load all built-in patterns."""
        from .builtin import DRUM_PATTERNS, BASS_PATTERNS, COMP_PATTERNS

        for style in DRUM_PATTERNS:
            self._patterns[style] = {
                "drums": DRUM_PATTERNS.get(style, []),
                "bass": BASS_PATTERNS.get(style, []),
                "comp": COMP_PATTERNS.get(style, []),
            }


# Global registry (lazy-loaded)
_registry: PatternRegistry | None = None


def get_pattern_registry() -> PatternRegistry:
    """Get the global pattern registry, initializing if needed."""
    global _registry
    if _registry is None:
        _registry = PatternRegistry()
        _registry.register_builtin_patterns()
    return _registry


def get_patterns(style: str) -> dict:
    """Convenience function for getting patterns."""
    return get_pattern_registry()[style]
```

**Instructions for agent**:
1. Replace `get_patterns()` in `accompy/patterns/__init__.py` with the registry pattern above
2. Prefer a clean public API over backward compatibility
3. Add `register_style()` convenience function for users

### Phase 4: Chord Resolution with Dependency Injection

**Goal**: Make chord-to-notes pluggable.

Create `accompy/chord_resolution.py`:

```python
"""Chord symbol to MIDI notes resolution."""

from typing import Callable

# Type alias for chord resolvers
ChordResolver = Callable[[str], list[int]]


def tonal_resolver(symbol: str, *, transpose: int = -12) -> list[int]:
    """Resolve using tonal package (default)."""
    from tonal.chords import chord_to_notes

    notes = list(chord_to_notes(symbol))
    return [n + transpose for n in notes] if transpose else notes


def music21_resolver(symbol: str, *, transpose: int = -12) -> list[int]:
    """Resolve using music21 (alternative)."""
    from music21 import harmony

    ch = harmony.ChordSymbol(symbol)
    notes = [p.midi for p in ch.pitches]
    return [n + transpose for n in notes] if transpose else notes


# Default resolver (configurable)
_default_resolver: ChordResolver = tonal_resolver


def get_chord_resolver() -> ChordResolver:
    """Get the current default chord resolver."""
    return _default_resolver


def set_chord_resolver(resolver: ChordResolver) -> None:
    """Set the default chord resolver."""
    global _default_resolver
    _default_resolver = resolver


def chord_to_notes(symbol: str) -> list[int]:
    """Convert chord symbol to MIDI notes using current resolver."""
    return _default_resolver(symbol)
```

**Instructions for agent**:
1. Create this module

### Phase 5: Event-Based MIDI Generation (Real-Time Ready)

**Goal**: Separate event generation from file writing to enable streaming.

Create `accompy/renderers/midi.py`:

```python
"""MIDI event generation (stateless, iterator-based)."""

from dataclasses import dataclass
from typing import Iterator, Sequence
from ..base import Score, AccompanimentConfig
from ..patterns.dataclasses import DrumPattern, BassPattern, CompingPattern


@dataclass(frozen=True)
class MidiEvent:
    """A single MIDI event."""

    time: float  # In beats
    channel: int
    note: int
    velocity: int
    duration: float


def generate_midi_events(
    score: Score,
    config: AccompanimentConfig,
    *,
    pattern_source: "PatternSource",
    chord_resolver: "ChordResolver",
) -> Iterator[MidiEvent]:
    """
    Generate MIDI events from score.

    Yields events in time order. Does NOT write files.
    This enables real-time streaming or batch file creation.

    Example:
        >>> events = generate_midi_events(score, config, ...)
        >>> for event in events:
        ...     send_to_synth(event)  # Real-time
    """
    patterns = pattern_source.get_patterns(config.style)
    beats_per_bar = score.time_signature[0]

    for repeat in range(config.repeats):
        current_beat = repeat * len(score.measures) * beats_per_bar

        for measure in score.measures:
            for chord_idx, chord_symbol in enumerate(measure):
                if chord_symbol in ("", "n", "N.C.", "NC"):
                    continue

                chord_start = current_beat + (
                    chord_idx * (beats_per_bar // len(measure))
                )
                notes = chord_resolver(chord_symbol)

                # Yield drum events
                yield from _drum_events(patterns["drums"], chord_start, config)

                # Yield bass events
                yield from _bass_events(patterns["bass"], chord_start, notes, config)

                # Yield comp events
                yield from _comp_events(patterns["comp"], chord_start, notes, config)

            current_beat += beats_per_bar
```

```python
class AccompanimentConfig:
    """Configuration for accompaniment generation."""

    # Core settings
    style: str = "swing"
    tempo: int = 120
    repeats: int = 2
    time_signature: tuple[int, int] = (4, 4)
```

### Phase 8: Real-Time Foundation

**Goal**: Add streaming support for future real-time use.

Create `accompy/realtime.py`:

```python
"""Real-time accompaniment support (foundation)."""

from typing import Iterator, Callable
from .base import Score, AccompanimentConfig
from .renderers.midi import MidiEvent, generate_midi_events


class RealtimeAccompaniment:
    """
    Real-time accompaniment player (foundation for future work).

    This class separates event scheduling from synthesis,
    enabling integration with real-time audio systems.

    Example (future usage):
        >>> player = RealtimeAccompaniment(config)
        >>> player.set_chords([('Dm7', 4), ('G7', 4), ('Cmaj7', 8)])
        >>> for event in player.events():
        ...     synth.play(event.note, event.velocity)
    """

    def __init__(
        self,
        config: AccompanimentConfig | None = None,
        *,
        on_event: Callable[[MidiEvent], None] | None = None,
    ):
        self.config = config or AccompanimentConfig()
        self._on_event = on_event
        self._score: Score | None = None

    def set_chords(self, chords) -> None:
        """Update the chord progression."""
        from .base import ensure_score

        self._score = ensure_score(chords)

    def events(self) -> Iterator[MidiEvent]:
        """Generate events for current chord progression."""
        if self._score is None:
            return
        yield from generate_midi_events(
            self._score,
            self.config,
            pattern_source=self.config.pattern_source or get_pattern_registry(),
            chord_resolver=self.config.chord_resolver or get_chord_resolver(),
        )
```

**Instructions for agent**:

## Summary: Key Architectural Changes

| Before | After |
|--------|-------|
| Monolithic 1400-line file | ~10 focused modules |
| Static pattern dicts | `PatternRegistry(MutableMapping)` |
| Hard-coded chord resolver | Pluggable `ChordResolver` protocol |
| File-only output | Event iterator + optional file I/O |
| Single FluidSynth path | `SynthesizerBackend` abstraction |
| Config scattered across args | `AccompanimentConfig` with DI hooks |

The key principles:
1. **Protocol-first** — define interfaces before implementations
2. **Iterator-based events** — enables both batch and real-time
3. **MutableMapping for registries** — Pythonic, extensible
4. **Dependency injection via config** — swap components without changing call sites
5. **Simplicity** — prefer fewer public entry points
