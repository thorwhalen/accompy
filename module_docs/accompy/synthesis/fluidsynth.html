accompy.synthesis.fluidsynth

FluidSynth synthesis backend.

Uses FluidSynth with SoundFonts to render MIDI to high-quality audio. FluidSynth is the default and most widely-supported backend for accompy.

class accompy.synthesis.fluidsynth.FluidSynthBackend(soundfont_path: Path | None = None)[source]

FluidSynth-based synthesis.

Uses SoundFont files (.sf2) to render MIDI with realistic instrument sounds. Supports both Python wrapper (midi2audio) and command-line FluidSynth.

Example

>>> backend = FluidSynthBackend()  
>>> backend.render_to_file(midi_path, output_path)
