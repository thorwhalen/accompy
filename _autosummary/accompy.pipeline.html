accompy.pipeline#

High-level pipeline API — one-call chord-to-audio conversion.

This module provides convenience functions that compose the registered converters into complete pipelines. It’s the simplest entry point.

Usage:

>>> from accompy.wips.pipeline import chords_to_midi, chords_to_audio
>>> midi_data = chords_to_midi("| Dm7 | G7 | Cmaj7 |")
>>> midi_data.write("output.mid")

>>> audio = chords_to_audio("| C | Am | F | G |")
>>> audio.write("output.wav")

>>> # Or with explicit control over which backend to use at each step
>>> midi_data = chords_to_midi("| C | Am |", resolver="music21", midi_gen="mido")

accompy.pipeline.file_to_audio(filepath, *, output_path=None, n_repeats=1, transpose=0, resolver=None, midi_gen=None, audio_renderer=None, soundfont=None, tempo=None, sr=44100)[source]#

Convert an iReal Pro HTML/URL file to audio.

Handles:

  • iReal Pro HTML files (exported from the app)

  • iReal Pro URL strings

  • Plain chord text files

Supports repeating the progression and transposing.

Parameters:

  • filepath (str) – Path to an iReal HTML file, or a chord text file

  • output_path (str | None) – Where to write audio. If None, uses filepath with .wav extension

  • n_repeats (int) – Number of times to repeat the progression (default 1)

  • transpose (int) – Semitones to transpose (positive=up, negative=down)

  • resolver (str | None) – Chord resolver backend

  • midi_gen (str | None) – MIDI generator backend

  • audio_renderer (str | None) – Audio renderer backend

  • soundfont (str | None) – Path to SoundFont file

  • tempo (int | None) – Override BPM (None = use file’s tempo or 120)

  • sr (int) – Sample rate

Return type:

AudioData

Returns:

AudioData

Example:

>>> file_to_audio("/path/to/song.html")
>>> file_to_audio("/path/to/song.html", n_repeats=40)
>>> file_to_audio("/path/to/song.html", transpose=5)

accompy.pipeline.rhythm_to_midi(chords, *, skeleton='whole_note', resolver=None, midi_gen=None, tempo=120, output_path=None)[source]#

Convert chords to MIDI using a rhythmic skeleton for restrike timing.

The skeleton defines when chords are struck within each measure. Each chord is sustained for the skeleton’s duration at that beat position.

Parameters:

  • chords (str | ChordSequence) – Chord string (e.g., "| Dm7 | G7 | Cmaj7 |") or ChordSequence.

  • skeleton (str | tuple[float, ...]) – Skeleton key, name, style, or duration tuple. Defaults to "whole_note" (one strike per measure).

  • resolver (str | None) – Chord resolver name (e.g., "pychord", "tonal").

  • midi_gen (str | None) – MIDI generator name (e.g., "pretty_midi", "midiutil").

  • tempo (int) – BPM (used if chords is a string).

  • output_path (str | None) – Optional path to write MIDI file.

Return type:

MidiData

Returns:

MidiData object.

Example

>>> md = rhythm_to_midi("| C | Am | F | G |", skeleton="tresillo")
>>> md.to_bytes()[:4]
b'MThd'
